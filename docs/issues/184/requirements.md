# Requirements: Issue #184 note 下書きの自動作成

## 1. 概要
素材ファイル（学習編: `security-study/<シリーズ>/Day<N>_study.md`、ニュース編: `security-news/cybersecurity_news_YYYY-MM-DD.md`）から note の下書きを自動作成する機能を実装する。

## 2. 要件
- **記事の型**（正本 §5）:
  1. 定型文: 「この記事の内容はPodCastとしても配信しています。（最新記事以外は過去の配信回をご参照ください）」
  2. Spotify 埋め込み: 番組（show）の Spotify URL（テキストリンクから埋め込みプレイヤーへの変換操作を含む）
  3. 目次ブロック: 埋め込みの直後
  4. 本文: 素材の逐語変換（要約・再編集禁止）。見出しレベルの変換ルールに従う（先頭の `## 📚 ...` のみ h3、他の `##` は h2、`###`/`####` は h3。ニュース編は `#` 見出しを本文に入れない）
- **ヘッダー画像**: シリーズ画像（前日記事の note API `https://note.com/api/v3/notes/<前日記事ID>` の `eyecatch` から取得）を設定する。
- **タイトル規則**:
  - 学習編: `<シリーズ名> 30日間学習Day<N>`
  - ニュース編: `<対象日> サイバーセキュリティニュースまとめ`
- **必須の品質チェック**: 下書き作成後に以下の3点を自動検証し、機械可読な JSON レポートとして出力する：
  1. 本文が素材の逐語変換になっていること（要約・削除・書き換えがないこと）
  2. 目次ブロックが埋め込みの直後にあること
  3. Spotify 埋め込みがプレイヤー表示になっていること（テキストリンクのままではないこと）
