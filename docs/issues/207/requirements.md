# 要求定義書: note 公開時のタグ・マガジン適用を確実にする (#207)

## 1. 背景と課題
- my-apps #205 で実装した note CLI の公開ステップにより、自動公開時にハッシュタグとマガジンが適用されない問題が発生している（`hashtag_notes`, `belonging_magazine_keys` が空）。
- 現状の `NoteEditorPage.ts` の `publishNote` におけるタグ・マガジン設定はベストエフォートであり、失敗しても検出できない。

## 2. 要件
1. **タグ設定の確実化**:
   - 入力後にチップ（タグ表示要素）が現れたことを確認し、現れなければリトライする。
   - 入力確定時の操作（Enter キーや候補選択等）を確実に実施する。
2. **マガジン設定の確実化**:
   - マガジン選択 UI を開き、対象マガジンを確実に選択して選択状態を確認する。
3. **結果の記録と終了コードへの反映**:
   - 結果 JSON の `details` に `tagsApplied`（実際に付いたタグ）と `magazineApplied`（適用されたマガジン名、失敗時 `null`）を記録する。
   - 要求した設定が適用できなかった場合はステータス・終了コード（例: 1）に反映させる。
4. **既存フロー維持**:
   - #205 の公開フロー全体の挙動、Spotify CLI、新規依存関係追加なし。
