# 設計書: note 公開時のタグ・マガジン適用確実化 (#207)

## 1. アーキテクチャと変更対象ファイル
- `src/pages/NoteEditorPage.ts`:
  - `publishNote` メソッドにおけるタグ入力・確定ロジックの改善（リトライ、チップ確認）。
  - マガジン選択 UI のオープン、検索/選択、選択済み確認ロジックの追加。
  - 公開後の実際に適用されたタグおよびマガジンの検証・取得処理。
- `src/noteCli.ts`:
  - `publishNote` の戻り値（`details` に `tagsApplied`, `magazineApplied` を含む）を受け取り、期待される設定が適用されなかった場合に適切な終了コード（例: 1）と失敗メッセージを出力するよう修正。
- テストファイル:
  - 関連する単体テスト（結果整形や設定検証ロジック等）の追加・更新。

## 2. 詳細設計
### 2.1 タグ設定
- ユーザー指定のタグ配列に対して各タグを入力。
- 入力フィールドにフォーカスし、タグ文字列を入力後、Enterキー送信または候補クリックを実施。
- 画面上にタグのチップ要素が出現したことを `waitFor` 等で検証。出現しない場合は最大リトライ回数（例: 3回）まで再試行。

### 2.2 マガジン設定
- マガジン追加ボタンまたは領域をクリックしてセレクトダイアログ/ポップアップを開く。
- 対象マガジン名に一致する要素を検索・クリック。
- チェックボックスや選択済み状態の表示を確認。

### 2.3 結果記録と終了コード
- `publishNote` の戻り値オブジェクトに `details: { tagsApplied: string[], magazineApplied: string | null, ... }` を含める。
- 呼び出し側（`src/noteCli.ts`）で、CLI引数で指定されたタグ・マガジンが実際に適用されたか（あるいは要求に対して不一致がないか）を判定し、不一致・失敗時は終了コード `1` を返して終了する。
