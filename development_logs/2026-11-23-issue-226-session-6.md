## 詳細実装
1. **公開ゲートの拡張 (`verifyPostPublishGate`)**:
   - `apiResponse` の `embedded_contents` に指定の `spotifyShowUrl` を含むエントリが存在するか検証。
   - 本文 HTML 内の figure が `embedded-service="oembed"` を持ち、かつ `embedded-content-key` が `embedded_contents` の key と一致するか検証。
   - 公開ページ HTML に `open.spotify.com/embed` の iframe が存在するか検証。
   - 記事タイトルが期待タイトル（SSOT 形式）と**完全一致**することを検証。
   - 1つでも不一致がある場合は `passed: false` および失敗理由を詳細結果に含める。

2. **埋め込み挿入経路の変更 (`setBodyAndEmbed`)**:
   - テンプレートテキスト段落 → Spotify URL段落 → 目次ブロック → 本文 HTML の順序で配置し、note エディタが URL 段落を埋め込みブロックに自動変換するのを待つように修正（最大10秒のポーリング、キー入力トリガー付き）。
   - 変換がタイムアウト内に起きない場合はフォールバックせず明示的にエラーで失敗。

3. **単体テストの追加**:
   - `tests/unit/noteDraftCreator.spec.ts` に4つのテストケース（正常ケース、症状A、症状B、タイトル不一致）を追加。
   - 既存の38件と合わせて全42件の単体テストが成功。
